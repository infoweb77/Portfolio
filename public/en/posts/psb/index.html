Senior iOS Developer.#

September 2019 — February 2021.#

www.psbank.ru

Product:#

Mobile banking application for SMEs featuring online banking, document management, and support chats.

Key Achievements:#

  • Transition to Adaptive Layout.#

Proposed migrating the team from Storyboard constraints to code-based adaptive layout using the SnapKit framework. The team implemented the transition. This not only significantly accelerated development but also later enabled a large-scale redesign. The updated design was well-received by users – the app’s average App Store rating increased from 3.2 to 4.6 within 6 months.

  • App Redesign.#

As a UX team member, I was responsible for the development and subsequent redesign of the main app screen. In some tasks, the redesign impacted over 80 screens.

  • Developed 5 Key Screens from Scratch.#

— Password Change Screen: with multi-factor verification; — Account Statement Screen: with filtering by dates and categories; — Support Chat Screen: (with instant message delivery via WebSocket); — Feedback Screen — Balance Widget.

  • Design System for the Team.#

Developed over 10 reusable UI components for the company’s design system, which accelerated new feature development across the entire team of 10 iOS developers.

  • Code Quality.#

Achieved >70% unit test coverage for my own code.

App Language: Swift + Objective-C (for legacy code). Core Frameworks: SnapKit, AFNetworking, ReactiveCocoa, IGList, SimpleKeychain, Crashlytics.
